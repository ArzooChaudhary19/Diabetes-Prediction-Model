# 🩺 Diabetes Prediction System

A machine-learning–powered, single-file full-stack application for clinical diabetes risk assessment. Built entirely in Python using **Streamlit** for the frontend and **scikit-learn** for the backend ML pipeline.

---

## 📌 Project Overview

This application trains four machine learning classifiers on the **Diabetes Prediction Dataset** (100 000 patient records) and exposes an interactive web interface with four main sections:

| Tab | Description |
|-----|-------------|
| 📋 Dataset Explorer | Browse the raw dataset, view descriptive statistics, and check data quality |
| 📊 Visualisations | Interactive charts — class distribution, feature histograms, correlation heatmap |
| 🤖 Model Performance | Side-by-side comparison of all four models, ROC curves, confusion matrix, feature importance |
| 🔮 Live Prediction | Enter patient data and get an instant diabetes risk score |

## 📊 Dataset

| Attribute | Details |
|-----------|---------|
| Source | Diabetes Prediction Dataset |
| Records | 100,000 patients |
| Features | 8 (gender, age, hypertension, heart disease, smoking history, BMI, HbA1c, blood glucose) |
| Target | `diabetes` (0 = Non-Diabetic, 1 = Diabetic) |
| Class balance | ~91.5% Non-Diabetic / ~8.5% Diabetic |

### Feature Description

| Feature | Type | Description |
|---------|------|-------------|
| `gender` | Categorical | Female / Male / Other |
| `age` | Numerical | Patient age in years (1–100) |
| `hypertension` | Binary | 0 = No, 1 = Yes |
| `heart_disease` | Binary | 0 = No, 1 = Yes |
| `smoking_history` | Categorical | never / No Info / current / former / ever / not current |
| `bmi` | Numerical | Body Mass Index (kg/m²) |
| `HbA1c_level` | Numerical | Glycated haemoglobin percentage |
| `blood_glucose_level` | Numerical | Blood glucose level (mg/dL) |
| `diabetes` | Binary | **Target** — 0 = No Diabetes, 1 = Diabetes |

## 🤖 Machine Learning Pipeline

```
Raw CSV  ──►  Preprocessing  ──►  Train / Test Split (80/20)  ──►  StandardScaler
                                                                         │
                  ┌──────────────────────────────────────────────────────┘
                  ▼
         ┌────────────────────┐
         │  Random Forest     │  ─ n_estimators=200, max_depth=10
         │  Gradient Boosting │  ─ n_estimators=150, lr=0.1
         │  Logistic Regression│ ─ max_iter=1000
         │  SVM (RBF kernel)  │  ─ probability=True
         └────────────────────┘
                  │
                  ▼
         Best model selected by AUC-ROC
         (5-fold stratified cross-validation)
                  │
                  ▼
         Saved to disk as diabetes_model.pkl
```

### Preprocessing Steps
1. Strip whitespace from string columns
2. Encode `gender`: Female→0, Male→1, Other→2
3. Encode `smoking_history` with ordinal mapping (No Info→0 … current→5)
4. Stratified 80/20 train-test split
5. StandardScaler fitted on training data only

## 🚀 Getting Started

### Prerequisites
- Python 3.9 or higher
- pip

### Installation

```bash
# 1. Clone / navigate to the project directory
cd Diabetes_Prediction

# 2. (Recommended) Create a virtual environment
python -m venv venv
venv\Scripts\activate       # Windows
# or
source venv/bin/activate    # macOS / Linux

# 3. Install dependencies
pip install -r requirements.txt
```

### Run the Application

```bash
streamlit run app.py
```

### Generate the Project Report (Word Document)

```bash
python create_report.py
```

This trains the model, generates all UI screenshots programmatically, and saves `Project_Report.docx` with all images embedded.

Streamlit will open **http://localhost:8501** in your browser automatically.

> **Note:** The first run takes ~30–60 seconds to train all four models. Results are cached; subsequent runs load instantly.
